The program is a console-based Contact Management System using Java ArrayList.
It stores contact details like name, phone number, and email.
  Main Features
    Displays a menu with options: Add, View, Update, Delete, Exit.
  Add Contact
    User enters name, phone, and email.
    Phone number is validated (10 digits, starts with 6–9).
    Email is validated using pattern matching.
    Duplicate phone numbers and emails are not allowed.
  View Contacts
    Displays all stored contacts with index numbers.
    Shows message if no contacts are available.
  Update Contact
    Shows existing contact list.
    User selects a contact by number.
    Updates name, phone, and email of selected contact.
  Delete Contact
    Shows contact list.
    User selects a contact to remove.
    Deletes the selected contact from the list.
