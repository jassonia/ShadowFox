This is a simple Java-based Inventory Management System used to manage product stock in a store. It allows users to add new products, update stock quantity, view available items, and remove products if needed.

Each product stores details like product name, ID, price, and quantity. The system automatically updates stock levels when items are added or sold.

The program runs in a menu-driven format and continues until the user exits. It helps in tracking inventory easily and avoiding stock shortages or overstocking.
