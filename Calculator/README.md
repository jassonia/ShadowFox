The program starts with a main menu offering Calculator, Unit Converter, and Exit options.
User selects either Calculator or Unit Converter module.
  Calculator Module
    Takes an initial number as input.
    Performs basic operations: +, −, ×, ÷, %.
    Supports scientific functions: sin, cos, tan, log, ln, sqrt, power, factorial.
    Result is continuously updated for chained calculations.
    Runs in a loop until user exits calculator.
  Unit Converter Module
    User selects a conversion category (length, weight, temperature, etc.).
    Chooses specific conversion type inside the category.
    Enters value and gets converted output instantly.
